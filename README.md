# Daily Ledger

A small installable web app (PWA) for a five-minute nightly log: spending in taka, sleep, mood, habits, time and to-dos, with streaks and charts.

- Works offline; everything is saved on the phone first.
- Optional sync to the owner's own Google Sheet through a private Apps Script web app (set up with a sync code in **Setup**). No personal data is stored in this repository.
- Install on Android: open the site in Chrome, then **⋮ → Install app** (or **Add to Home screen**).
